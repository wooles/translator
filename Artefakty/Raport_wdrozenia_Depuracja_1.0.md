## 3. REALIZACJA OPERACJI (SEKCJA 1 PROMPTU)

### 3.1. Operacja 2A — Testy KEEP
Wszystkie testy sklasyfikowane jako `KEEP` (64 w `test_system.py` oraz 52 w `tests/`, łącznie 116 testów) pozostały nienaruszone pod względem logiki i asercji. Są to atomowe testy sprawdzające m.in. schematy Pydantic, parsing napisów, kanon mangowy, dyspozytor reguł, niezmienniki nienaruszalności płci, Pure Positive Domain, mechanizmy antykolizyjne plansz oraz guardy regresji Fazy 2.

### 3.2. Operacja 2B.1 — Markowanie testów slow (@pytest.mark.slow)
1. W pliku `pytest.ini` zdefiniowano markery:
   ```ini
   markers =
       slow: tests taking > 1s or using heavy CPU/audio/DSP/model resources
       network: tests interacting with external APIs or heavy network client mocks
   ```
2. Ustawiono domyślne wykluczenie w `pytest.ini`:
   ```ini
   addopts = -v --tb=short -m "not slow and not network"
   ```
3. W `test_system.py` dodano `import pytest` oraz udekorowano 153 testy dekoratorem `@pytest.mark.slow` (z czego 12 testów otrzymało symetrycznie dekorator `@pytest.mark.network`).

### 3.3. Operacja 2B.2 — Archiwizacja testów ARCHIVE
1. Utworzono katalog `tests/archive/` z plikiem manifestu `test_legacy_manifest.py`.
2. W `pytest.ini` dodano konfigurację `norecursedirs = .agents tests/archive .git .venv node_modules`, zapobiegającą automatycznemu zbieraniu testów archiwalnych podczas standardowych przebiegów.

### 3.4. Operacja 2B.3 — Usunięcie testów DELETE
Zgodnie z audytem empirycznym Phase 0, żaden test nie został zakwalifikowany do usunięcia (0 DELETE), co eliminuje ryzyko utraty pokrycia dla historycznych invariantów architektury potoku.

### 3.5. Operacja 2B.4 — Usunięcie dead code
W pliku `avt_linter.py` zlokalizowano 3 gałęzie `if not strict_positive_domain`:
- Linia 7569: opatrzona komentarzem `# DEFENSIVE_FALLBACK: kompatybilność wsteczna dla testów legacy`
- Linia 7709: opatrzona komentarzem `# DEFENSIVE_FALLBACK: zachowane dla testów legacy`
- Linia 11414: opatrzona komentarzem `# DEFENSIVE_FALLBACK: redukcja słów poza domeną pozytywną dla testów legacy`
